# Home Security Operations Center (Home SOC)

## Overview

This repository documents my journey of building a Home Security Operations Center (SOC) from scratch using open-source technologies.

The goal is to gain hands-on experience with enterprise cybersecurity concepts including:

- Security Monitoring
- Log Analysis
- Threat Detection
- Incident Response
- Network Security
- Linux Administration

## Hardware

### SOC Server

- HP EliteDesk Mini
- Linux Mint Cinnamon
- 8 GB RAM
- Static IP: 10.0.0.44
