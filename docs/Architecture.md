# Home SOC Architecture

## Objective

Build a home Security Operations Center capable of monitoring endpoints, collecting logs, detecting attacks, and visualizing security events.

## Hardware

### SOC Server

- Model: HP EliteDesk 705 G2 Desktop Mini
- CPU: AMD PRO A8-8600B
- RAM: 8 GB DDR3
- Operating System: Linux Mint 22.3

## Planned Components

- Wazuh Manager
- Wazuh Dashboard
- Wazuh Indexer
- Suricata IDS
- Windows Endpoint Agent
- GitHub Documentation

## Network

Home Router
├── Main Windows PC (Agent)
└── Linux Mint Home SOC Server
